동행이음 | 구현 상태와 검증 범위 | 2026-11-21

이 문서는 과거의 '개발환경만 준비' 기록보다 우선하는 현재 상태입니다.

[코드 구현]
앱: SMS Auth 연동, 가입 안내, 기관 연결 수락, 배정 일정, 임시 방문, 시작/휴게/복귀/종료, 위치 동의·권한 분기, 로컬 저장·재전송, 현장 설명, 시각 정정 요청, 기관 답변, 로그아웃 전 미전송 확인.
웹: SMS 로그인, 기관 현황·방문 조회, 기관 범위 지원사/이용자 배정·일정, 후보 근거·질문·답변, 정정 및 일정 요청 승인, 감사 조회.
서버: 사용자 JWT 검증, 웹 CSRF, 기관 범위 RLS 연동, 원본/유효 시간 계산, 규칙·과거 시간 패턴 분석.
DB: 기관·프로필·소속·초대·이용자·담당 배정·일정·일정 요청·방문·이벤트·위치·메모·확인 사건·정정·감사 로그, 정책 및 RPC.

[시험 통과]
Python 도메인/API 테스트: 11개 통과.
Flutter 정적 분석 및 시간 합산 단위 테스트.
Android debug APK 빌드 성공. 실물 실행/백그라운드 안정성 시험과는 다름.
PGlite PostgreSQL에서 스키마 실행·기관 간 접근 차단·역할 제한·오프라인 재전송 멱등성·원본 변경 차단·후보 비공개·양측 답변 검사.
브라우저 로그인·대시보드·상세·메뉴 이동·작은 화면 가로 넘침·JavaScript 오류 검사.
브라우저 업무 데이터는 테스트 fixture이며 실제 클라우드 연결 시험이 아님.
스크린샷: docs/screenshots. 테스트 데이터가 표시된 파일 이름에는 test-fixture 표시.

[외부 설정으로 막힌 항목]
Supabase 연결 권한 오류 → 클라우드 DB 미적용. schema.sql은 로컬 시험 완료.
SMS 업체 미설정 → 실제 문자 인증 미시험. 사용자 요청에 따라 유료 설정 보류.
iOS → Mac/Xcode·서명·실물 시험 필요.

[기획 전체 대비 아직 남은 기능/검증]
1. 상시 서버 분석 스케줄러·푸시 알림: 현재 활성 관리자 탭에서 주기 점검. 통신 가능 시 2~5분은 목표이며 보장 수치 아님.
2. 센서 기반 휴대폰 정지 2시간: 아직 수집/판정 미구현. 휴대폰을 두고 나갔는지 위치만으로 확정 불가.
3. 배터리: 60초 요청·휴게 종료 중단·전송 묶음 적용. 적응형 측정과 실제 절감률은 미검증.
4. 전체 와이어프레임 화면 수와 1:1 완성은 아님. 일부 화면을 탭·바텀시트로 묶음. 지도 시각화·음성 입력·운영자 웹·기관 이동 UI는 후속 작업.
5. 기관 이동은 DB 단일 소속 제약으로 막으며, 미전송 로컬 자료를 확인하는 운영자 이관 절차는 아직 미구현.
6. AI는 기록 시간 단일 특징의 실험 모델. 합성 자료 기반 성능은 실제 적발률로 사용할 수 없음. 장기 체류는 정상 돌봄일 수 있음.
7. 보관·삭제·동의 철회 서버 처리, 대규모 조회·장기 저장 최적화, 백업 복구, 실서비스 인증 요청 제한/남용 방지, 보안 종합 검토 미완료.
8. 웹 세션은 만료 시 재로그인. 자동 토큰 갱신은 후속 작업.
9. 앱 로컬 이력은 해당 기기 기준. 기기 교체·서버 이력 복원 UI는 후속 작업.
10. 후보는 최초 탐지 스냅샷. 재분석 결과의 후보 해제 비교 화면은 후속 작업.

[현장 시험 순서]
가상 기관 A/B와 테스트 계정 → 배정 → 정상 방문 → 휴게 → 종료 → 4시간/30분 합산 확인.
네트워크 끊기 → 시작·휴게·종료 → GPS 중지 확인 → 네트워크 복구 → 원본 수/시각 중복 없음 확인.
위치 권한 거부/서비스 꺼짐 → 시간만 정상 기록 확인.
화면 잠금·절전·앱 전환·강제 종료를 나눠 수집 공백과 배터리를 기록.
정정 요청 → 승인 → 원본 유지/유효 시간 변경 → 사건 재검토 → 양측 답변 후 완료.
다른 기관 계정으로 원본·위치·답변 조회 불가 확인.
같은 이용자의 충분한 가상 과거 기록으로 패턴 후보 작동 확인 후 오탐 사례를 분리 기록.
