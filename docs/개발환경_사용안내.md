# 개발환경 사용 안내

확인일: 2026-11-21. 현재 단계는 환경 구성이며 기능 코드/기본 앱/DB 테이블은 생성하지 않았습니다.

- 가상환경: C:\Project\Dolbom_ieum\.venv
- FastAPI 0.165.0 / Uvicorn 0.54.0 / Jinja2 3.1.6

- Flutter 3.47.0 / Dart 3.13.0 기존 버전 유지

## 팀원 환경 복원
프로젝트 폴더에서 실행합니다.

    uv sync --locked
    uv run python --version
    uv pip check

.env.example을 .env로 복사하고 지정된 프로젝트 URL과 공개 키를 입력합니다.
.env 및 .venv는 Git에서 제외됩니다. uv.lock과 .python-version은 공유 대상입니다.
가상환경 활성화는 필수가 아닙니다. Python 명령 앞에 uv run을 사용하세요.
기능 코드가 없으므로 아직 앱/웹 서버 실행 명령은 없습니다.
관리자 웹은 Jinja2이므로 별도 npm 설치가 필요하지 않습니다.

## Supabase
서버 DB는 지정된 Supabase PostgreSQL, 로그인은 Supabase Auth입니다.
앱 오프라인 저장은 SQLite를 유지합니다.
Python 클라이언트 초기화 및 공개 키로 Auth 설정 조회 HTTP 200 확인.
/rest/v1/ 루트 문서 조회는 HTTP 401, Secret API key required 응답.
이는 해당 엔드포인트의 권한 제한이며, 테이블 읽기/쓰기가 검증됐다는 뜻이 아닙니다.
관리 연결 도구도 프로젝트 조회 권한 부족 상태였습니다.
관리 도구 권한 연결 및 테이블/RLS 설계는 별도 단계로 남아 있습니다.
사용자 가입/로그인, DB 변경, 테스트 사용자 생성은 하지 않았습니다.
비밀 키를 공개 앱이나 Git 저장소에 추가하지 않습니다.

## Android 남은 작업
사용자가 아래 명령으로 표시되는 약관을 직접 읽고 동의합니다.

    flutter doctor --android-licenses
    flutter doctor -v

Android 실기기를 USB 디버깅으로 연결하고 휴대폰의 연결 승인을 하거나 에뮬레이터를 실행한 뒤 확인합니다.

    flutter devices

현재는 연결된 Android 기기를 확인하지 못했습니다.
Flutter 프로젝트를 생성하지 않았으므로 앱 빌드와 Gradle/JDK 조합은 아직 미검증입니다.
위치/움직임/SQLite용 Flutter 패키지는 앱 프로젝트 생성 단계에서 선정·잠금합니다.
Windows 데스크톱용 Visual Studio C++는 이번 범위에 필요하지 않습니다.
iPhone은 Mac에서 Xcode와 별도 실기기 환경이 필요합니다.
