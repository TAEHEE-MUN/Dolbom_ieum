동행이음 | 실행 및 DB 적용 안내 | 2026-11-21

1. 현재 상태
개발 경로: C:\Project\Dolbom_ieum
휴대전화 SMS 인증 연동 코드가 있으며, SMS 업체 가입·결제·발송 설정은 사용자 요청으로 보류했습니다.
공개 키는 클라이언트용입니다. DB 생성이나 운영자 권한을 제공하지 않습니다.
현재 Supabase 연결의 프로젝트 관리 요청이 권한 오류이므로 클라우드 테이블을 생성하지 않았습니다.

2. Python 서버
PowerShell:
  cd C:\Project\Dolbom_ieum
  uv sync --locked
  uv run uvicorn backend.main:app --host 127.0.0.1 --port 8000
웹: http://127.0.0.1:8000
API 문서: http://127.0.0.1:8000/docs
.env에 SUPABASE_URL / SUPABASE_PUBLISHABLE_KEY를 설정합니다.
.env는 Git 제외 대상이며 .env.example은 값 없는 예시입니다.
웹은 HTTPOnly 쿠키 인증과 CSRF 검증을 사용합니다. 세션 만료 시 재로그인합니다.
실서비스는 HTTPS가 필요합니다. 현재 서버는 개발 PC용입니다.

3. Supabase DB 최초 적용
대상: imwyxesukjjvjnneaeif 프로젝트. 사용자가 빈 DB라고 확인한 프로젝트입니다.
프로젝트 관리 권한 연결 후 기존 테이블 존재 여부를 다시 확인합니다.
아직 빈 프로젝트인 경우 SQL Editor에서 db/schema.sql 전체를 한 번 실행합니다.
다음으로 db/operator_setup.sql을 실행합니다.
schema.sql은 최초 생성용이며 반복 실행용이 아닙니다. 기존 데이터가 생긴 이후에는 별도 변경 SQL 검토가 필요합니다.
개발 프로젝트를 바꿀 경우 URL과 공개 키도 함께 변경합니다.
PGlite 검증은 Supabase 자체 Auth/REST 통합 검증을 대체하지 않습니다.

4. 인증 및 최초 관리자
실제 발송 시 Supabase Phone Auth와 SMS 제공업체 설정이 필요합니다. 비용 발생 설정은 현재 보류 상태입니다.
문자 발송 전 시험이 필요하면 프로젝트 관리자가 Supabase의 테스트 전화번호/고정 코드 설정을 검토해 사용합니다. 이 작업은 아직 하지 않았습니다.
최초 관리자가 문자 인증으로 가입한 후, 운영자가 SQL Editor에서 아래 함수를 실행합니다.
  select private.provision_agency('시험 기관명', '+8210본인번호', '관리자 이름');
실제 값을 직접 입력하며 공개 저장소에 전화번호를 넣지 않습니다.
일반 로그인 사용자는 이 함수를 실행할 수 없습니다.
지원사는 앱 가입 → 이름·안내 확인 → 기관 관리자에게 연결 코드 전달 → 관리자의 연결 요청 → 앱에서 기관 수락 순서입니다.
기관당 관리자 및 지원사 권한은 DB가 확인하며 화면 숨김만으로 접근을 제한하지 않습니다.

5. Flutter 앱
  cd C:\Project\Dolbom_ieum\apps\mobile
  flutter pub get
  flutter run --dart-define-from-file=config/development.json
config/development.example.json을 참고합니다. development.json은 Git 제외입니다.
현재 API_BASE_URL은 Android 에뮬레이터용 http://10.0.2.2:8000 입니다.
실물 Android는 API_BASE_URL을 PC의 LAN 주소로 변경하고 서버를 --host 0.0.0.0 로 실행합니다. 같은 Wi-Fi와 방화벽 접근을 확인하세요.
이는 신뢰할 수 있는 개발 네트워크에서만 시험합니다. release 빌드에서는 HTTPS를 사용합니다.
iOS는 Mac/Xcode에서 서명·권한·실물 기기를 준비하고 HTTPS API 주소를 사용합니다. Windows에서 iOS 빌드를 검증하지 않았습니다.
디버그 APK:
  flutter build apk --debug --dart-define-from-file=config/development.json
Android SDK 약관은 사용자가 flutter doctor --android-licenses로 직접 읽고 선택합니다.
앱 패키지 ID는 개발용이며 실제 출시 전 소유 조직의 식별자를 확정해야 합니다.
