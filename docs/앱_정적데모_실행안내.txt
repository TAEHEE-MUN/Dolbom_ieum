돌봄이음 — Figma 활동지원사 앱 정적 프론트
작성: 2026-11-23

1. 실행
프로젝트: C:\Project\Dolbom_ieum\apps\mobile

PowerShell에서:
  cd C:\Project\Dolbom_ieum\apps\mobile
  flutter pub get
  flutter run -d chrome -t lib/main_demo.dart --web-port 5174

브라우저의 로그인 버튼을 누르면 오늘 방문으로 이동합니다.
정적 데모이므로 실제 전화번호/비밀번호는 입력하지 않아도 됩니다.
회원가입은 안내창만 표시하며 실제 계정을 생성하지 않습니다.

Android 기기 또는 에뮬레이터에서는:
  flutter run -t lib/main_demo.dart -d <flutter devices에 표시된 기기 ID>

Android 데모 APK:
  flutter build apk --debug -t lib/main_demo.dart

Mac에서도 같은 Flutter 프로젝트를 열 수 있습니다.
iOS 기기 실행에는 macOS/Xcode 및 해당 기기 설정이 필요합니다.
이번 작업에서는 iOS 실기기 실행을 검증하지 않았습니다.

2. 로컬 웹 빌드
  flutter build web -t lib/main_demo.dart --no-web-resources-cdn
  python -m http.server 5174 --bind 127.0.0.1 --directory build/web
접속: http://127.0.0.1:5174
HTML 파일을 더블클릭하지 말고 위 HTTP 서버를 통해 실행하세요.
기본 데모 진입점은 main_demo.dart입니다. 기존 main.dart는 백엔드 연동용입니다.

3. 화면 바로 확인
웹 주소에 ?screen=화면이름 을 붙여 각 프레임을 독립적으로 확인합니다.
예: http://127.0.0.1:5174/?screen=recordDetail
Android: flutter run -t lib/main_demo.dart --dart-define=DEMO_SCREEN=recordDetail

4. 구현 파일
lib/main_demo.dart : 서버 없이 실행하는 별도 진입점
lib/demo/app.dart : 공통 앱 틀, 상단/하단 메뉴, 스크롤
lib/demo/components.dart : 공통 버튼/카드/상태/입력창/원본 캐릭터
lib/demo/screens.dart : 화면 20개 및 화면별 입력/전환
lib/demo/model.dart : 메모리 기반 상태와 프레임 ID 매핑
lib/demo/figma_assets.dart : Figma SVG 자산 매핑
assets/figma : 원본 Figma 아이콘/캐릭터 SVG
assets/fonts : Noto Sans KR 글꼴 및 OFL 라이선스
test/demo_test.dart : 레이아웃/스크롤/방문/답변/정정 흐름 검사

5. 데모 범위
실제 Supabase 인증, API 호출, GPS 수집, 기관 전송을 실행하지 않습니다.
‘전송 완료’, ‘위치 기록 중’ 등 문구와 시간은 원본 디자인의 시연 데이터입니다.
시계는 실시간으로 증가하지 않습니다. 화면별 예시 시간이 표시됩니다.
입력한 현장 사유, 답변, 변경 요청은 실행 중 메모리에서 반영됩니다.
새로고침/재실행/로그아웃 시 초기화되며 디스크/DB에 저장되지 않습니다.
기존 백엔드 연동 코드와 DB 스키마는 이번 작업에서 변경하지 않았습니다.

6. 검사 명령
  flutter analyze
  flutter test
  flutter test --dart-define=CAPTURE_DEMO=true
마지막 명령은 build/demo-review에 20개 화면의 상단/하단 비교 PNG도 생성합니다.
검사 기준: 402x874 기본 크기, 320x640 글자 1.5배.

7. 디자인 적용 기준
사용자가 제공한 최신 Figma의 돌봄이음 명칭과 녹색(#4CA771)/연녹색(#EAF9E7)을 사용합니다.
공통 좌우 여백 20, 기본 버튼 최소 높이 62, 보조 버튼 58, 탭/터치 영역 48 이상.
모바일 화면 폭은 최대 402로 통일하며 좁은 화면에서는 실제 폭에 맞춥니다.
상단과 하단 메뉴는 고정하고 본문은 세로 스크롤합니다.
긴 화면은 축소하지 않으며 입력 시 키보드에 맞춰 본문 높이가 조정됩니다.
상태는 색뿐 아니라 문구/아이콘으로도 표현합니다.
디자인과 동일한 색상을 유지했으며, 전체 접근성 인증을 의미하지 않습니다.
